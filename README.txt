# قالب موقع مقاول حفر وترحيل ودفان

هذا قالب HTML جاهز كتصميم احترافي مرجعي للموقع.

مهم: Google Sites لا يرفع ملف HTML كقالب موقع كامل مباشرة. استخدم التصميم كمرجع، ثم أعد بناء الأقسام داخل Google Sites، أو استضف ملف HTML على خدمة استضافة ثم أضفه في Google Sites عبر Embed إذا كانت الخدمة تسمح بذلك.

قبل النشر:
1. استبدل رقم الهاتف 966500000000 برقمك.
2. استبدل رابط واتساب.
3. أضف صور مشاريعك الحقيقية.
4. أضف اسم المؤسسة والشعار والعنوان.
5. أضف روابط Google Maps وحسابات التواصل.
